# FRONTIER — fully open source

FRONTIER is MIT-licensed end-to-end. There is no closed product split anymore.

- No license keys / HWID locks
- No telemetry
- Loader and cheat source ship in this repo

Historical note: older docs described a public “base” vs private “product” split. That model is retired; keep everything public under [LICENSE](../LICENSE).

Binaries (`*.exe`, `*.sys`, `dist/`, release zips) stay gitignored — build locally or publish via GitHub Releases.

# Contributing

Thanks for poking around.

## Quick tips

1. Build **Release | x64** before you PR
2. Offset-only PRs are fine — say which Roblox version
3. Keep diffs focused; don’t reformat the whole tree

## Don’t land

- Webhooks, tokens, `.env`, private keys
- Prebuilt `exe` / `pdb` (already gitignored)
- Telemetry that phones home

## Style

Match what’s already in the file. Header-heavy C++ is normal here.
